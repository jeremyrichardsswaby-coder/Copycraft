# Copycraft# Copycraft (Voxel Sandbox 3D)

A browser-based 3D voxel sandbox game featuring a 1,000-block world (-500 to +500), mountain ranges, snow biomes, crafting, and hostile mobs.

🎮 **[Play Copycraft Live](https://jeremyrichardsswaby-coder.github.io/Copycraft/)**

## Features
- **Expansive 3D World**: Explore a 1000x1000 block terrain with mountains, snow, and deep bedrock (-500).
- **Game Modes**: Switch seamlessly between **Survival** and **Creative** modes.
- **Crafting & Smelting**: Use the 3x3 crafting table and furnace to build items and survive.
- **Camera Perspectives**: Toggle between 1st-person and 3rd-person views on the fly.

## Controls

| Key / Input | Action |
| :--- | :--- |
| **W A S D** | Move & Swim |
| **SPACE** | Jump / Swim Up / Fly |
| **SHIFT** | Sprint / Fly Down |
| **LMB / RMB** | Attack / Mine / Place Block |
| **E** | Open Inventory & Crafting |
| **1 - 9** | Select Hotbar Slot |
| **G** | Toggle Survival / Creative Mode |
| **P** | Switch 1st / 3rd Person Camera |
| **ESC** | Pause Game |
